Persiapan Install Node.js LTS di komputer/server. ## 2. Jalankan Buka terminal di folder ini: ```bash npm install ``` Kemudian: ```bash npm start ``` Buka: `http://localhost:3000` Untuk perangkat lain dalam jaringan yang sama, buka alamat IP komputer server, misalnya: `http://192.168.1.10:3000` ## 3. Agar bisa dipakai dari internet Upload folder ini ke VPS/hosting yang mendukung Node.js, lalu gunakan HTTPS/domain. Set environment variable: `JWT_SECRET=buat-string-rahasia-yang-panjang` Jangan memakai secret bawaan untuk produksi. ## 4. Cara tes chat 1. Buat akun A dengan nomor A. 2. Buat akun B dari perangkat/browser lain dengan nomor B. 3. Dari akun A, masukkan nomor B pada kolom tambah kontak. 4. Buka kontak B dan kirim pesan. 5. Pesan disimpan di SQLite dan tersedia dari perangkat lain. ## Catatan Versi ini menyediakan chat teks realtime dengan polling + WebSocket notifikasi. Tombol suara/video masih placeholder. Panggilan nyata memerlukan WebRTC + signaling dan sebaiknya TURN server. PIN di server disimpan sebagai bcrypt hash, bukan plaintext.
